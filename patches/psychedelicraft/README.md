# Psychedelicraft creative-tab patch

Основа: официальный исходный код [Sollace/Psychedelicraft](https://github.com/Sollace/Psychedelicraft), тег `1.8.9+1.20.1`, лицензия MIT.

В стандартной версии мод регистрирует четыре вкладки: `general`, `pharmaceuticals`, `drinks` и `weapons`. При большом количестве модов Minecraft разносит их по разным страницам.

Исправление NeLegal изменяет только `PSItemGroups`:

- сохраняет вкладку `general`;
- добавляет в неё препараты, напитки и коктейли Молотова в конце списка;
- не регистрирует три дополнительные вкладки;
- не изменяет игровые предметы, рецепты, эффекты и сохранения.

В репозитории не публикуется полный сторонний JAR. Рабочая сборка создана из пользовательского `ru-FIXED` JAR заменой только `ivorius/psychedelicraft/item/PSItemGroups.class`. Побайтовая проверка подтвердила отсутствие изменений во всех остальных файлах архива.
