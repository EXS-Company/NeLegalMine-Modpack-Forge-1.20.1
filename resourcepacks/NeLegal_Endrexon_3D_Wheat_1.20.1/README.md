# NeLegal Endrexon 3D Wheat

Авторский MVP объёмной пшеницы для Minecraft Java Edition 1.20.1.

## Что меняет

- сохраняет ванильный блок `minecraft:wheat` и его обычную игровую механику;
- заменяет только визуальные модели восьми стадий `age=0..7`;
- использует встроенные текстуры `minecraft:block/wheat_stage0..7`;
- постепенно увеличивает плотность геометрии от 4 до 13 элементов;
- не требует OptiFine, Forge-кода, Fabric, Java или Gradle.

## Установка

1. Возьмите соседний файл `NeLegal_Endrexon_3D_Wheat_1.20.1.zip`.
2. Поместите его в папку `resourcepacks` профиля Minecraft 1.20.1.
3. Включите пакет выше сторонних паков, которые также меняют пшеницу.

Исходник зрелой стадии находится в `source/blockbench/wheat_stage7.bbmodel`. Скрипт `source/build.ps1` воспроизводит модели, Blockbench-файл и устанавливаемый ZIP.

## Граница проверки

Структура и связи файлов проверяются автоматически. Внешний вид, мерцание прозрачностей и FPS необходимо проверить вручную в Minecraft.
