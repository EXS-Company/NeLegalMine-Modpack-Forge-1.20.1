# Проверка Endrexon 3D Wheat

Сборщик `source/build.ps1` проверяет:

- чтение каждого `.json`, `.mcmeta` и `.bbmodel`;
- наличие вариантов `age=0..7`;
- наличие всех восьми моделей, указанных в blockstate;
- количество элементов по стадиям: `4, 5, 6, 7, 8, 9, 11, 13`;
- суммарно 63 элемента;
- координаты геометрии в пределах блока `0..16`;
- наличие `pack.mcmeta` и моделей внутри готового ZIP.

Не считается проверенным без запуска игры:

- визуальная плотность и отсутствие z-fighting;
- корректное сочетание с другими активными ресурс-паками;
- производительность на больших полях;
- внешний вид с Oculus-шейдерами.
